# Täielik dump (esimene static)

Manifest ja README on repos. **Täielikud kataloogifailid** (~2 MB kokku) on dumpitud projektis:

- `artifacts/pengu-catalogs-full.zip`
- või kaust `artifacts/pengu-catalogs/catalog/`

## Kuidas üles panna (telefon / arvuti)

1. Ava https://github.com/koerakutsa/pengu-catalogs
2. **Add file → Upload files**
3. Tõmba zip lahti ja lae üles kaust **`catalog/`** (movie + series JSON-id)
4. Commit
